## 6. 作った機能の要点（レビュー時の見どころ）

- **タグ削除**: 参照が残っていると 409。`?force=1` で強行。理由は ON DELETE SET NULL で
  シナリオの起動条件などが黙って消えるため。
- **権限**: 一斉配信・タグ・スコア・計測リンク・流入経路・プールの**書き込み**は owner/admin。
  閲覧は全員。**注文・発送はあえて開けたまま**（日々のカウンター業務のため）。
- **オートメーション**: 既存JSONは非変換。知らないアクション種別・知らないキーが1つでもあれば
  JSON編集に落として警告を出す。アクション種別を変えると params を空にする（キー残留で消えるため）。
- **一斉配信の差し込み**: 本文に差し込みがあれば multicast → 1人ずつ push に切替。
  「全員」宛てと重複除外配信では**使用不可**（送信時と画面の両方で拒否）。
